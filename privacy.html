应用介绍隐私政策使用说明

隐私政策

MAX Gmail Readonly Intake · 更新日期：2026-10-29

访问的数据与目的

本工具仅供应用所有者个人使用。工具请求 Gmail 只读权限与离线访问，用于识别、整理并保存所有者明确授权账户中的指定自发自收研究参考邮件，供个人研究功能按需参考。程序按指定账户、发件人及收件人限制业务处理范围；API 权限本身可读取邮件。

使用与传输

授权的研究参考正文可传输至 MAX 配置的模型服务进行推理、比较与总结。它不会被描述为全部只在本机处理。邮箱账户信息、邮件头、无关私人邮件及原始附件不进入公开交付；研究结论只按所有者另外授权的范围交付。

本工具不出售 Google 用户数据，不将其用于广告定向，不使用这些数据训练通用模型。本工具使用从 Google API 获取的信息遵守 Google API Services User Data Policy，包括 Limited Use 要求。

存储与保护

OAuth 客户端和刷新令牌保存在所有者设备的受限私有目录，不写入代码库、模型研究输入、公开网站或交付内容。邮件原件保存在所有者控制的私有存储；近期研究正文按当前 180 自然日窗口维护，归档原件由所有者管理。模型服务对已传输研究正文的处理与保留同时适用相应服务的数据政策。

撤销与删除

所有者可在 Google 账户的第三方连接管理中撤销本工具授权。撤销会阻止后续授权访问，不会自动删除此前已保存的数据。本地和归档数据由所有者管理；如需删除，可通过 Google 同意页面显示的支持邮箱联系应用所有者安排处理。

网站与联系方式

本说明站不设登录、表单、分析脚本或邮件上传功能。静态托管由 GitHub Pages 提供，访问日志的处理适用 GitHub 隐私声明。授权和数据问题请联系 Google 同意页面列出的用户支持邮箱；请勿在公开 GitHub issue 中提交任何私人数据或凭据。
